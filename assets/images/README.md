# Profile Image Location

## Instructions

Your professional profile photo should be stored in this directory as:
- **Filename:** `profile.png` (currently configured for .png format)
- **Recommended specifications:**
  - **Size:** 150×150 pixels minimum (will be displayed as circular image)
  - **Format:** PNG (current), or JPG
  - **Aspect ratio:** Square (1:1) works best for circular display
  - **File size:** Keep under 500 KB for fast loading

## How to update

1. Prepare your professional headshot as a square image (1:1 aspect ratio)
2. Save it as `profile.png` (to match current configuration)
3. Replace the existing file in this directory: `assets/images/profile.png`
4. The image will automatically appear on your home page as a circular professional headshot
