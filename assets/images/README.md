# Profile Image Location

## Instructions

Upload your professional profile photo to this directory as:
- **Filename:** `profile.jpg` (or `.png`)
- **Recommended specifications:**
  - **Size:** 150×150 pixels (will be displayed as circular image)
  - **Format:** JPG or PNG
  - **Aspect ratio:** Square (1:1) works best for circular display
  - **File size:** Keep under 500 KB for fast loading

## How to upload

1. Prepare your professional headshot as a square image (1:1 aspect ratio)
2. Save it as `profile.jpg` or `profile.png`
3. Place it in this directory: `assets/images/`
4. The image will automatically appear on your home page as a circular professional headshot

## Current status

The website is currently set to display an image at `assets/images/profile.jpg`. Once you upload your photo, it will automatically appear on the home page.
